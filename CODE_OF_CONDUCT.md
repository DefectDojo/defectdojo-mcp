# Code of Conduct

DefectDojo is an OWASP project, and this repository follows the [OWASP Code of Conduct](https://policy.owasp.org/operational/code-of-conduct). Everyone who takes part here, in issues, pull requests, discussions and any other project space, is expected to follow it.

In short: treat people with respect and dignity, act honestly, respect licenses and give credit for others' work, and do not harass, intimidate or demean anyone.

## Reporting

If you see or experience behavior that breaks the Code of Conduct, contact the OWASP DefectDojo project leaders:

- Aaron Weaver, aaron.weaver@owasp.org
- Matt Tesauro, matt.tesauro@owasp.org
- Greg Anderson, greg.anderson@owasp.org

Reports are handled in confidence. Serious or repeated violations may also be raised with OWASP through the process described in the OWASP Code of Conduct.
